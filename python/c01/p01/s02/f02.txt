How Does the Print Function Work?

The terminal is the area where you can see text output from a program.
The print() function sends text and other values to the terminal.
You just need to put the string Hello world! in between the opening and closing parentheses you use to call the print function:
print('Hello world!') # Hello world!

You can also use the print function to show multiple values, or arguments, at once by separating them with commas.
print('My favorite colors are', 'blue', 'green', 'red')
# Output: My favorite colors are blue green red
