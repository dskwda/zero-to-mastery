How Do Functions Work in Python?

What Are Functions?
Functions are reusable pieces of code that run when you call them. Python provides built-in functions, including print().
Another helpful built-in function is input(), which lets you prompt the user for input:
name = input('What is your name?') # User types "Kolade" and presses Enter  
print('Hello', name) # Output: Hello Kolade
On the other hand, int() converts a number, a boolean, or a string representing an integer into an integer:
print(int(3.14)) # 3
print(int('42')) # 42
print(int(True)) # 1
print(int(False)) # 0 

Defining and Calling Functions
You can also write your own custom functions. To do that, you use the def keyword, followed by the name you want to give your function, a pair of parentheses, and a colon. Then on a new line, you write the code your function should run. The code the function runs is also referred to as the function's body.
Here's an example of a custom function named hello that prints the string Hello World to the terminal:
def hello():
    print('Hello World')
To run the function, you need to call it with its name followed by a pair of parentheses:
hello() # Hello World
Notice the indentation before print('Hello World'). Python relies on indentation to determine which groups of statements belong together. These groups of statements are called code blocks.

Using Parameters and Arguments
Here's another simple function that prints the sum of two numbers to the terminal:
def calculate_sum(a, b):
    print(a + b)
You can see that our function, calculate_sum, has a and b in its parentheses, separated by a comma. Those are called parameters. Think of parameters as placeholder variables that act as "slots" for the values you pass into functions when you call them.
To use the parameters, you have to pass in "arguments". Arguments are the values you pass to a function when you call it.
Here's how to call the calculate_sum function to sum together the numbers 3 and 1:
calculate_sum(3, 1) # 4
If you call the function without the correct number of arguments, you'll get a TypeError:
calculate_sum()
# TypeError: calculate_sum() missing 2 required positional arguments: 'a' and 'b'

Positional and Keyword Arguments
The arguments in calculate_sum(3, 1) are positional arguments. Python matches them to parameters by their position: 3 goes to a, and 1 goes to b.
Here's a function where the order of the arguments matters:
def introduce(name, age):
    print(f'My name is {name} and I am {age} years old.')
introduce('Alice', 25)
# My name is Alice and I am 25 years old.
If you swap the positional arguments, name receives 25 and age receives 'Alice':
introduce(25, 'Alice')
# My name is 25 and I am Alice years old.
You can also pass keyword arguments by writing the parameter name followed by = and a value. Python matches these arguments by name, so you can write them in a different order:
introduce(age=25, name='Alice')
# My name is Alice and I am 25 years old.
Here, name='Alice' passes 'Alice' to the name parameter. It does not assign a variable named name outside the function.
You can combine positional and keyword arguments, but the positional arguments must come first:
introduce('Alice', age=25)
# My name is Alice and I am 25 years old.
Putting a positional argument after a keyword argument causes a SyntaxError:
introduce(name='Alice', 25)
# SyntaxError: positional argument follows keyword argument
You also cannot supply a value for the same parameter more than once:
introduce('Alice', name='Bob', age=25)
# TypeError: introduce() got multiple values for argument 'name'
In this call, the positional argument 'Alice' already supplies the value for name. Passing name='Bob' supplies a second value for that same parameter.

Returning Values From Functions
Functions also use a special return keyword to exit the function and return a value. If you don't explicitly use return, Python will return None by default.
As you learned on identity operators, None represents the absence of a value. Here, it indicates that the function has not returned an explicit result.
Here's an example:
def calculate_sum(a, b):
    print(a + b)
my_sum = calculate_sum(3, 1) # 4
print(my_sum) # None
You can see that the calculate_sum function prints the sum of a and b, but it doesn't return anything explicitly. So when we assign its result to my_sum, the value is actually None. To fix that, you can use the return keyword to send back the result:
def calculate_sum(a, b):
    return a + b
my_sum = calculate_sum(3, 1)
print(my_sum) # 4
Now, calculate_sum returns the sum of a and b, which gets stored in my_sum.
